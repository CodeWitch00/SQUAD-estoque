|  | Layout não responsivo ou ausência da logo da empresa. | **0,5** |
|  | Interface desalinhada, sem responsividade e sem identidade visual. | **0,0** |

## **TF • Monografia**

| **Critério** | **Descrição dos Critérios de Avaliação** | **Nota** |
| --- | --- | --- |
| Qualidade da Escrita e Textualização | Redação acadêmica em linguagem culta e impessoal, com excelente coesão, coerência, clareza técnica e sem erros ortográficos/gramaticais. | **1,0** |
|  | Texto compreensível, mas com **poucos erros** ortográficos/gramaticais (1 a 3 erros) ou frases informalmente estruturadas. | **0,5** |
|  | Texto com **muitos erros** de ortografia, pontuação ou problemas graves de concordância que prejudicam a leitura acadêmica. | **0,0** |
| Introdução e Fundamentação Teórica | Introdução bem delimitada e Referencial Teórico consistente, fundamentado em autores da área com referências citadas no texto. | **1,0** |
|  | Contextualização clara, mas a Fundamentação Teórica é superficial ou faltam citações de autores importantes para embasar o tema. | **0,5** |
|  | Introdução confusa e Fundamentação Teórica desconexa do problema prático do projeto. | **0,25** |
|  | Não apresentou Introdução ou Fundamentação Teórica. | **0,0** |
| Estrutura e Normas ABNT | Estrutura formal completa conforme ABNT (Capa, Folha de Rosto, Folha de Aprovação, Resumo/Abstract com Palavras-chave, Sumário e Referências), com formatação impecável de margens, fontes, espaçamentos e citações. | **1,0** |
|  | Apresenta a estrutura completa, mas possui falhas pontuais de formatação ABNT (ex: espaçamentos, recuos de parágrafo ou padrão de citações fora da norma). | **0,5** |
|  | Faltam elementos pré-textuais essenciais (ex: ausência de Resumo/Abstract ou Folha de Aprovação) e apresenta diversos erros de formatação ABNT. | **0,25** |
|  | Não segue as normas ABNT nem o padrão estrutural exigido para o trabalho. | **0,0** |
| Declaração de Aceite / Conclusão Anexada | Anexou a Declaração de Aceite/Conclusão devidamente preenchida e **assinada pela empresa parceira/cliente** no final do documento. | **1,0** |
|  | Não anexou a Declaração de Aceite ou a entregou sem a assinatura da empresa. | **0,0** |
| Conclusão e Referências Bibliográficas | Conclusão que responde diretamente aos objetivos propostos e lista de Referências contendo todas as obras citadas no texto, exatamente no padrão ABNT NBR 6023. | **1,0** |
|  | Conclusão coerente, mas a lista de Referências apresenta inconsistências de formatação ABNT ou links sem data de acesso. | **0,5** |
|  | Conclusão superficial e ausência/erros graves na listagem das Referências. | **0,0** |

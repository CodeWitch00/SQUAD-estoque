## Procedimento

1. Abrir o HTML local no navegador atualizado.
2. Definir o viewport exato nas ferramentas de desenvolvedor.
3. Percorrer e revisar todo o fluxo do perfil.
4. Capturar a página inteira em PNG, sem barras do navegador ou dados pessoais.
5. Salvar com um dos nomes acima nesta pasta.
6. Conferir legibilidade, dimensões e correspondência com o commit do protótipo.
7. Anexar as três imagens e o link do PR/commit ao cartão.

# Protótipos de interface

Referências visuais e navegáveis das interfaces do MVP.

## Demonstração

- [Abrir protótipo navegável no GitHub Pages](https://codewitch00.github.io/SQUAD-estoque/)
- [Abrir o login localmente](login.html)
- [Visualizar sem GitHub Pages](https://html-preview.github.io/?url=https://raw.githubusercontent.com/CodeWitch00/SQUAD-estoque/main/docs/05-ux/prototipos/login.html)

O GitHub Pages publica a pasta `docs/` da branch `main`. A página inicial abre o login compartilhado; os links do login e das telas dos dois perfis responderam HTTP 200 em 18/09/2026.

Para navegar pelo protótipo, use `vendedor@squad.com` ou `lojista@squad.com` com qualquer senha preenchida.
Essa demonstração é estática: não autentica na aplicação MVC nem altera o estoque.
